# Published local measurement collection

This collection uses one warmup and five measured trials per mode and image size. `raw.csv` retains all warmups, timings, PNG digests, exit codes and links to individual stdout/stderr logs. `summary.json` is generated by `bench/plot.py`; `environment.json` records the source/executable fingerprints and toolchain commands.

The coordinator reserved this interval for RayTracing. No other agent benchmark and no operation from the measuring agent ran concurrently. The host operating system and unrelated desktop activity were not controlled. Both modes use the same CUDA-built executable, with four OpenMP threads, 50 samples/pixel and depth 20.

This followed an explicitly identified [preliminary collection](../wsl-2026-09-12/README.md) that overlapped a file cleanup. Both datasets are retained. Current results use only this second collection, with no cherry-picking or removal of measured observations.

Exact invocation for this collection, after the documented CUDA build:

```bash
python3 bench/measure.py --binary build_gpu_audit/raytracer --mode both --threads 4 --output bench/results/wsl-2026-09-12-isolated
python3 bench/plot.py bench/results/wsl-2026-09-12-isolated
```

For a new collection, choose a new output directory. The committed directory is protected against accidental overwrite by the harness.
